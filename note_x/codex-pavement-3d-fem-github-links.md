# Pavement 3D FEM GitHub Links

Search date: April 19, 2026

Assumption:
- The request "pavement 3F fem analysis" was interpreted as "pavement 3D FEM analysis."

## Best Direct Matches

1. FAARFIELD public mirror
- https://github.com/Johann-Cardenas/FAARFIELD-2.1.1
- Best match for airport pavement / FAA-style analysis.

2. FLEX3D
- https://github.com/primuszp/FLEX3D
- Strong direct match for 3D FEM flexible pavement analysis.

3. Flexible-Pavement-FEA
- https://github.com/tufailmab/Flexible-Pavement-FEA
- ABAQUS/Python workflow for flexible pavement FEA.

4. Pavement-Modelling
- https://github.com/givemefive2002/Pavement-Modelling
- Python scripts for pre/post-processing ABAQUS 3D FEM pavement models.

5. ANN-FEM-Pavement-Modulus-Backcalculation
- https://github.com/paanchuk9080/ANN-FEM-Pavement-Modulus-Backcalculation
- FEM-assisted modulus backcalculation workflow.

6. C-FLEX2D
- https://github.com/primuszp/C-FLEX2D
- Relevant 2D pavement FEM companion repo.

## Smaller / Less Proven Repos

1. Finite-element-modeling-Pavement-BY-ABAQUS
- https://github.com/gemmylink95/Finite-element-modeling-Pavement-BY-ABAQUS

2. Finite-Element-Moldeling-Pavement-BY-ABAQUS
- https://github.com/gemmylink95/Finite-Element-Moldeling-Pavement-BY-ABAQUS

3. pavement_abaqus
- https://github.com/ck1212/pavement_abaqus

4. Abba-ko-kassoo
- https://github.com/AarkaSon/Abba-ko-kassoo
- Abaqus model of a rigid pavement slab using lightweight aggregate.

## False Positive To Ignore

1. FEMmodelPavementCells
- https://github.com/inatamara/FEMmodelPavementCells
- This is not pavement engineering; it is about biological pavement cells.

## Search Notes

- Strong public GitHub repos specifically for `airport pavement FEM` and `rigid pavement FEM` were limited.
- The FAARFIELD mirror is still the most relevant public source for airport pavement analysis.
- The other useful repos are mostly flexible-pavement FEM, ABAQUS helpers, or research workflows rather than polished end-user tools.
